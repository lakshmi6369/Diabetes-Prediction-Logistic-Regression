# Diabetes Prediction using Logistic Regression

## Project Overview
This project predicts diabetes using the Pima Indians Diabetes Dataset.

## Dataset
Pima Indians Diabetes Database from Kaggle.

## Algorithm
Logistic Regression

## Preprocessing
- Invalid zero values replaced with missing values
- Median imputation
- StandardScaler
- Balanced Logistic Regression

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## Conclusion
The Logistic Regression model demonstrates the use of supervised classification for diabetes prediction. Glucose and BMI are important positive contributors to the model. This project is intended for educational purposes and not for medical diagnosis.# Diabetes-Prediction-Logistic-Regression
